  • What is JavaScript?

    +

    JavaScript is a programming language used to make web pages interactive.

  • What is the DOM?

    +

    The DOM represents the HTML page as objects that JavaScript can access and modify.

  • What does addEventListener do?

    +

    It allows you to run a function when a specific event happens, such as a click.

  • What does classList.toggle() do?

    +

    It adds a class if it doesn't exist and removes it if it already exists.
